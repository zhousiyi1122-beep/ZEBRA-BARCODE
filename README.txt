Zebra Barcode Display – PWA package

Files:
- index.html: barcode generator (Code 128), default value 24
- manifest.webmanifest: installable app settings
- sw.js: offline cache
- icons/: Android home-screen icons

To install as an app on Android:
1. Publish this folder to a GitHub repository using GitHub Pages (HTTPS).
2. Open the published GitHub Pages address in Chrome or Samsung Internet.
3. Open the browser menu and choose "Install app" or "Add to Home screen".
4. Confirm. The Zebra Barcode icon will appear on the phone's home screen.
5. Open it once while online; after that it can work offline.

The generated barcode is created locally in the browser. No barcode data is uploaded.
